# План реализации: старый Майкл как онлайн-скин

## Проблема
Смена модели игрока через SET_PLAYER_MODEL в GTA V меняет не только внешний вид, но и активного персонажа. Из-за этого появляются эффекты, похожие на переключение на Franklin/Trevor, и ломается поведение героя.

## Цель
Сделать внешний вид "старого Майкла" без смены активного персонажа и без нарушения миссий/активностей.

## Подход
1. Не использовать смену player model как основной способ.
2. Реализовать косметическую подмену текущего педа:
   - волосы
   - борода
   - одежда
   - черты лица
   - пропорции
3. Для этого использовать:
   - компоненты педа
   - пропорции/голову
   - текстуры/дополнительные варианты одежды
4. Сохранять и восстанавливать состояние при включении/выключении.

## Возможные шаги
- Найти подходящие компоненты для старого Майкла.
- Подобрать одежду и волосы, похожие на образ.
- Применять их через SetPedComponentVariation / SetPedHeadBlendData / SetPedHairColor и т.д.
- Сохранять исходные значения, чтобы вернуться обратно.

## Примечание
Это будет не "моделька из онлайн", а полноценная косметика текущего Майкла без смены героя.
