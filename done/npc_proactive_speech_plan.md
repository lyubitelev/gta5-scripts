# План: проактивная речь — ТОЛЬКО для именных персонажей

NPC заговаривает **сам, без Z**. Область строго ограничена **известными персонажами** (`IsKnownCharacter` — те, у кого уникальная модель в таблице `KnownCharacters`: Michael, Franklin, Trevor, Amanda, Lester, Lamar и т.д.). Толпа/случайные педы проактив НЕ получают (нет спама, нет лишних расходов).

## Суть
Сейчас вход один: Z → запись → STT → LLM → TTS. Добавляем **второй вход без записи**: `TriggerProactive(ped, eventText)` — вместо реплики игрока подаётся **описание события**, дальше тот же пайплайн LLM → TTS → `ApplyAction`. STT не нужен (игрок молчит) — это только LLM+TTS.

Память даёт «вау»: приветствие может опираться на сводку («всё ещё должен мне за ту лодку?»).

## Ограничение области (главное)
- Кандидат на проактив — только пед, чья модель есть в `KnownCharacters` (`IsKnownCharacter == true`).
- Проверка дёшево: среди ближних педов берём тех, у кого `GetOrCreateIdentity(ped).IsKnownCharacter`.

## Триггеры (для именных)
1. **Приветствие по приближению** — игрок подошёл ближе ~6 м к именному, которого давно не приветствовал → тот сам здоровается (с опорой на память). Один раз за «встречу» (сбрасывается, когда игрок отошёл далеко и вернулся).
2. **Реакция на сильные действия игрока рядом:** достал оружие / выстрелил / угон / появился розыск → реплика в характере.
3. (Позже) **Прощание вслед**, когда уходишь; **комментарии компаньона** об обстановке.

## Три кита (обязательно)
1. **Кулдауны:** на персонажа (~45–60 с), глобальный (не чаще ~раза в 12 с на весь мир), + вероятностные ворота на «слабые» триггеры. Именных в мире мало → риск спама низкий, но кулдаун всё равно нужен.
2. **Уступает игроку:** проактив запускается только если свободно (`!_isProcessing`, окно вовлечения не занято, ничего не проигрывается). Нажатие Z отменяет проактив (уже есть `_currentCts`/отмена).
3. **Стоимость:** только LLM+TTS, триггерим редко. Опционально гибрид — тривиальное (привет/толкнул) готовыми фразами без LLM, «вкусное» — через LLM с памятью.

## Контекст в LLM
Вместо текста игрока — событие: «The player just walked up to you» / «The player just drew a weapon near you», плюс флаг **UNPROMPTED**: «you speak FIRST, briefly, in character; greet/react, don't wait to be asked». Остальной промпт (персона, состояние, vehicle-контекст, MEMORY) — как есть.

## Поведение
Заговорил → повернулся к игроку (`TASK_TURN_PED_TO_FACE_ENTITY`, есть), мимика губ (есть), громкость по дистанции (есть). Проактив = тот же показ ответа, инициатор — игра. Реплики проактива тоже пишутся в память именного.

## Интеграция
- `AiController.Update` (троттлинг ~1–2 с): искать ближних именных, проверять триггеры и кулдауны, дёргать `TriggerProactive`.
- `TriggerProactive` — облегчённый аналог `ProcessInteractionAsync` без STT: `userText = eventText`, дальше LLM (с флагом proactive) → TTS → очередь в главный поток → `ApplyAction` + сохранение памяти.
- `GetNpcResponseAsync` — добавить признак `proactive`/событие (или вшить в промпт через спец-маркер).
- Кулдауны/«уже поприветствован» — словари по `ModelKey` + времена; «встреча» сбрасывается по дистанции.

## Порядок реализации (минимум → вау)
1. **Приветствие именных по приближению** (кулдаун + один раз за встречу, с памятью). Самый сочный эффект, низкий риск.
2. **Реакции именных на сильные действия игрока** (оружие/выстрел/угон/розыск) с кулдауном и вероятностью.
3. Позже — прощание вслед и комментарии компаньонов; гибрид «готовые фразы + LLM».

## Риски
- Спам → кулдауны + «один раз за встречу» + вероятность.
- Наложение TTS → один проактив зараз, проактив уступает игроку.
- Цена → только именные, редкие триггеры, опц. готовые фразы для мелочей.
